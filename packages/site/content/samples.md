Each sample is a folder in the repository under `examples/`. Copy the `lynter.yaml` to the root of your vault or repository. Every rule id in these files exists in the current core, and a test lints each sample on every build.

| Sample | Use it for | Folder |
|---|---|---|
| starter-vault | A personal vault: frontmatter order, heading case, lists, contractions | [examples/starter-vault](https://github.com/klappe-pm/lynter/tree/master/examples/starter-vault) |
| team-handbook | A shared vault: a policy note type, file name checks, em dash replacement | [examples/team-handbook](https://github.com/klappe-pm/lynter/tree/master/examples/team-handbook) |
| agent-memory | Folders agents write to: strong text removal, joined lines, key order | [examples/agent-memory](https://github.com/klappe-pm/lynter/tree/master/examples/agent-memory) |
| docs-site | Docs beside code: stem headings, kebab-case names, prose list reports | [examples/docs-site](https://github.com/klappe-pm/lynter/tree/master/examples/docs-site) |

See the [examples gallery](/examples/) for before and after output you can open in the playground.
